# 同步练-对战版

**儿童互动对战学习**：把**人教版官方课本的知识点测验**变成游戏积分——答对一题，小乌龟就往前跑一格、火箭升高一段、楼再盖一层……谁先答对 8 题谁赢。题目按**现行最新版人教版教材**（2022 版课标教材）的单元 → 知识点随机生成，一到六年级 × 语文 / 数学 / 英语；练的是课本，玩的是游戏，寓教于乐。可以打机器人、两人一台 iPad 同屏，或者每人一台设备扫码进同一个房间；不想比的时候，它就是一份安静的同步练习。

在线：**[tongbulian.jiaci.app](https://tongbulian.jiaci.app)**（手机 / iPad 打开后可以添加到主屏幕，像 App 一样全屏打开）

- **课本知识点 = 游戏积分**：对战和练习用的是同一套按教材出的题，每答对一题得 1 分，比分直接驱动游戏画面（赛跑、赛车、开火车、火箭升空、热气球、游泳、爬梯子、挖宝、钓鱼、盖楼、种花、孵蛋、吹泡泡、摘果子、点亮星星、拼图、拔河、跷跷板、抢旗、融冰、拆城堡，二十一种 canvas 实时绘制的小场景），连对 / 反超 / 冲刺有提示和音效，赢了撒彩纸。孩子以为在玩游戏，其实每一分都是一道课本题。
- **三种对战方式**：打机器人（三档快慢，会一个一个按数字、也会答错）；两人一台 iPad 左右同屏；每人一台设备扫码进同一个房间——红队 / 蓝队 / 观战，每队最多 6 人，两队齐了自动开始，结果页「下一章」接着打本册下一个知识点。
- **也能安静地练**：一轮 8 题，做完打勾。随机出题，不是题库：每个知识点一个生成器，题干配十格阵、实物图、钟面、人民币、图形、数轴、尺子（三年级有毫米尺）、竖式（加减乘，除法是课本的厂字形）、秤面、分数图、方格上的图形、统计表、月历、排队，四年级的计数器、算盘、量角器、条形统计图、藏宝平面图与指南针等可视化教具；答错当场用教具演示讲解（凑十法 / 破十法有动画）。
- **语文按课出题**：一、二、三年级语文按统编新教材（一上 2024 秋、一下 2025 春、二上 2025 秋、二下 2026 春、三上 2026 秋、三下 2027 春）每课一个知识点——识字课、汉语拼音、课文、古诗、文言文和每个单元的语文园地。题目只从这一课的生字、课文和拼音里出：听音选字、看拼音选字、看字选读音、看图选字、选词填空、课文问答、数笔画、第一笔、加一加 / 减一减、偏旁、反义词、古诗作者；拼音课还有第几声、拼一拼、找声母韵母、平舌翘舌、前鼻后鼻、字母表与音序；二年级再加词语表的看拼音选词语 / 听音选词语、多音字（词里标红的字怎么读）、近义词和部首查字法；三年级按课本的单元出略读课文、预测与寓言单元的问答、文言文的字词意思、古诗的注释与名言出处。考认字的字用田字格楷体、不注音也不读出来——注了音就等于把答案摆在眼前。
- **三年级数学**：按 2022 版课标新教材（三上 2026 秋、三下 2027 春）逐页读过课本出题——混合运算、毫米分米千米、克千克吨（曹冲称象的故事）、多位数乘一位数、数字编码、线和角、分数、轴对称 / 平移 / 旋转、除数是一位数的除法、长方形和正方形的周长、面积、复式统计表、年月日与 24 时计时法、小数。分数竖着排（分子在上、分母在下）、读「八分之三」；小数、分数的答案用选项卡；年份按位读「二零二四年」，14:30 读「十四点三十」。
- **四年级数学**：按 2022 版课标新教材四上（2026 秋）逐页读过课本出题——亿以内、亿以上数的读写（读法照课本：每级末尾的 0 不读，中间连续几个 0 只读一个零）、大小比较、改写成用「万」「亿」作单位的数与「四舍五入」求近似数、1 亿有多大、角的再认识与量角器读数、画角、多位数乘两位数（竖式照课本排出两次乘得的数）、积的变化规律、用估算解决问题、总量与分量 / 单价数量总价 / 时间速度路程三种数量关系、平行和垂直、平行四边形和梯形、单式与复式条形统计图、八个方向（寻找宝藏）。国家中小学智慧教育平台上的四年级下册还是旧版课本，新版出来之前只有上册。
- **识字不多也能自己玩**：题目里的汉字都标拼音（语文考认字的那个字除外），每道题自动朗读（预先合成好的语音片段拼播，不依赖浏览器 TTS）；对战里让孩子照着做的提示（怎么练、你叫什么、扫码进入、等大家进来、输口令……）在出现的那一刻也会读出来。
- **没有惩罚**：练习不计时、不扣分、没有排行、没有解锁链；对战答错不扣分、不锁题，输了只写「差一点点！」，也不改练习进度、不存战绩。
- **纯前端、不要账号**：进度只存在本机浏览器里，`dist/` 放到任何静态托管就能跑；只有对战的多设备模式需要一个小小的内存中继服务（仓库 `server/`）。
- **开源、干净**：代码全部以 MIT 许可公开在这个仓库里，谁都能查、也能自己部署一套；免费、无广告、不用注册、不收集个人信息。首页底部和每张静态页页脚都写着这一句并链到仓库；「分享给朋友」一键调系统分享面板（微信里教用右上角菜单，电脑上复制一段话），对战结果页还能「分享战绩」。
- **配老师讲的视频课**：知识点地图上每个知识点的完成状态旁边有「▶ 视频」，新窗口打开[国家中小学智慧教育平台](https://basic.smartedu.cn)上这一节的同步课，先听老师讲，再来练、来对战。平台上还没有新教材这一节同步课的，先链到新教材的精品课或旧版教材里对应的课，用虚线框标出来（旧版教材的写「▶ 旧版」）。
- 界面中文 / 英文一键切换，题目、拼音、朗读都跟着切。

**目前内容**：一年级数学 31 个知识点、二年级数学 33 个知识点、三年级数学 46 个知识点、四年级数学 22 个知识点（上册）、一年级语文 76 个知识点、二年级语文 71 个知识点、三年级语文 67 个知识点全部可练可对战，单元、小节与题目内容按国家中小学智慧教育平台上的 2024–2027 年新版电子课本（数学含「数学游戏」和带 ☆ 的综合与实践；语文每课一个知识点，外加每个单元的语文园地；清单见[知识点清单](#知识点清单)）；其它年级和英语在目录里占位「敬请期待」，逐步补。

```bash

npm run preview
npm run typecheck    # vue-tsc --noEmit
npm test             # vitest run：生成器多种子自洽、拼音对齐、语料一致、题目渲染、整站集成、对战状态机与中继服务

npx vitest run -t "凑十"                                                          # 按用例名过滤
```

## 孩子怎么用

首页顶部栏是「⚔️ 同步练」+「对战版」标记，标题下面一条每种游戏的图标和一句「答对课本题就得分，谁先答对 8 题谁赢！」（带拼音）；顶栏的「🔑 加入对战」输口令就能进别人建的房间。

1. 选学科 → 选年级（上线的年级每一册一张卡，画着那本课本的封面，点哪一张就进那一册）→ 进入**知识点地图**（上册 / 下册两个页签，每个单元一张卡，知识点是圆形节点；当前册记在地址里，从题目返回还在同一册）。
2. 点一个知识点，直接到它的「练习」页，问「怎么练？」（带拼音，会读出来）：第一张「自己练」默认就选着，点「开始」开始练习，一轮 8 题，进题自动读题干，🔊 可以再听一遍；用**数字键盘**或**四选一卡片**作答；答对撒花、夸一句，答错读出并显示正确答案（有教具的知识点会演示一遍），点「我知道了」继续。一轮做完是结算页，和对战的结果页一样三个按钮：「下一章」（本册的下一个知识点）、「再练一次」、「不练了」。练习页排得紧凑（顶部栏在这一页缩小一号），常见手机竖屏上题目、教具和作答区一屏放得下，答错时连同讲解也不用往下滚。
3. 做完一轮就算「已完成」，地图上打勾。没做完的节点下面有 8 格进度条和这一轮的「x 题 · 对 y · 错 z」，中途退出下次接着做；做完的显示那一轮的对错数，再进去就开新的一轮重新计。家长也可以在地图上直接点状态标签手动标记 / 取消，不用做题。
4. 想比一比：点知识点后在「怎么练」里选打机器人、两人一台或各用各的，开始。第一次默认选着「自己练」，之后默认选着上次开始时选的那张。

没有解锁、没有星星、没有排行，不计时、不扣分，想练哪个点哪个；顶部栏的 🔊 / 🔇 可以关掉声音。每个知识点内部分三档难度，一轮里按约 60% 当前档、25% 低一档、15% 高一档混合出题（当前档暂固定为第 1 档，没有更低档，实际 85% / 15%）。

应用里有一页「❓ 帮助与说明」（首页底部、对战设置页页头的「怎么玩」都能进），分对战怎么玩、游戏规则、游戏技巧、学习内容与题目、常见问题五节，中英文随界面切换；在线版另有一张不用 JS 的静态页 [tongbulian.jiaci.app/help/](https://tongbulian.jiaci.app/help/)。

## 对战模式

对战的题和练习页是同一套生成器按教材知识点出的（同一个知识点、同样的难度档），只是把「答对」变成了「得分」：🔴 红队和 🔵 蓝队各答各的，**谁先答对 8 题谁赢**；答错不扣分、不锁题，1 秒多显示正确答案就出下一题。对战不改地图上的练习进度，也不存战绩。

### 怎么练

点知识点就到这一页（标题「⚔️ 练习」+ 知识点名，下面问「怎么练？」）：顶上两个玩法页签「⚔️ 对战」「🥊 打怪兽」（打怪兽见下面一节），对战页签里四张卡（自己练、打机器人、两人一台、各用各的，各画一幅示意图，一眼看出模式；手机竖屏上两排各两张）和「开始」，第一次默认选着「自己练」，之后默认选着上次开始时选的那张；机器人快慢、选游戏、改名字都在页头「⚙️ 配置」里。

- **打机器人**：机器人有自己的题，按 🐢 慢 / 🐰 中 / 🚀 快三档节奏答题，会一个一个按出数字、也会答错，还有表情（🤔 想题、🤖 在按、😄 答对、😅 答错）。进题自动读题。
- **两人一台**：一台 iPad / 电脑横着放，左右各一个人的题和键盘，可以同时按（上面的实拍视频就是这种）。不自动读题，点 🔊 读自己的；点了就一定读完，另一边这时点了排在后面接着读。
- **各用各的**：每人一台设备，进同一个房间（见下一节）。用 `file://` 打开或托管方没有中继服务时这张卡置灰。

**竞技场一律横向**：左区红队、右区蓝队，游戏画面在上方横条或左右之间的竖条（游戏说了算）；每人一行题目 + 键盘 / 选项卡。两队一眼分清：队区整块队色描边，队名条实心队色白字，题目里的按钮白底、队色描边、队色底边；自己那一队的队名条上标「我」，本机不能操作的行蒙一层半透明遮罩、右上角写「对方」或「队友」（两人一台两边都是自己，不标不蒙），只观战的设备顶栏写「👀 观战中」。手机竖着拿会提示横过来，横屏用紧凑版布局（题干与键盘左右并排，键盘按栏高缩放）；平板 / 手机进竞技场会试着全屏（电脑不会）。

**名字**：开始前什么都不问，点「开始」就打。没自定义过的，每一方随机分到一只小动物、名字就叫它（🐰 小兔、🐱 小猫……），两边一定不一样（多设备时撞了由服务器给后进来的人换一只）；每次打开页面随机一次，同一次里再来一局、下一章不变。想用自己的名字或小动物，在「⚙️ 配置」里改（名字可以输入或点现成的 🐰 小兔、🐯 小虎……，两人一台的右边也在那里，「🎲 随机」回到随机），改过的优先。名字只显示、不朗读，播报用「红队 / 蓝队」。

### 各用各的：多设备房间

1. 一个人在设置页选「各用各的」→「建房间」，屏幕上就是三个二维码：左边红队、右边蓝队、下面观战，每个带 6 位数字口令、链接和「复制链接」；建房的这台设备先只观战。
2. 红队的人扫红队码、蓝队的人扫蓝队码进来（不方便扫码就点顶栏的「🔑 加入对战」输那个身份的口令；不问名字），先看到「三方连接状态」窗口：红队、蓝队各有谁、观战几人，没到的一方写「等待连接…」。二维码页上每个码下面也写着谁已进入；一队有人后，建房的设备可以「以另一队进入」自己上场，或「以观战方进入」只看。
3. **红蓝两队都有人进来就自动开始**，不用谁点开始。每台设备上都是完整的竞技场，**只有自己那一行能操作**，别人的行实时显示他在答什么、按了什么、对还是错；队伍比分 = 队里所有人答对的题数之和（每队最多 6 人，人数不要求相等），用时按服务器时钟算。
4. 结果页三个角色一模一样：「下一章」在同一个房间接着打这一册的下一个知识点（游戏换成那一章的，不用重新建房、重新扫码，可以一直打到这一册最后一个）、「再来一局」、「不玩了」（关掉房间，大家一起回地图）；谁先点就按谁的，三台设备一起变。

题目在各自设备上生成与判分（同一个种子，服务器只记谁答到第几题、对了几题）；断线自动重连并接回原座位（页面回到前台立刻重连）；一台设备只算一个人（同一个浏览器再开一个标签页会顶掉先开的）；主持人（建房的设备）掉线 20 秒内回来不换人，超过才把主持权交给最早在线的人。房间只在服务器内存里（没人 10 分钟或建房 3 小时后销毁），不落库、不记内容日志；链接 `#/battle/<房间号>?t=red|blue|watch`，房间号本身就是密钥。页面版本比服务旧时自动更新重载再进，连不上时提示检查网络。

### 语音通话

不在同一个屋子里的人可以开麦说话（两台设备在一个屋子里会啸叫，不用开）。只有「各用各的」有：**房间里每个人自动能听到开了麦的人说话**，不用点任何东西；连接状态窗口、二维码页底部和竞技场顶栏各有一个 🎤 键只管自己的麦克风，**点了才会向浏览器要麦克风**（进房、重连、刷新后都是关着的，绝不自动开），开着带绿圈、自己说话时脉动，开了麦的成员名字旁边也有一颗小 🎤、他说话时跟着动；再点一下关掉并释放麦克风，还能继续听。开 / 关、拒绝了权限、浏览器不支持（微信内置浏览器要换到系统浏览器打开）、名额满了（一个房间最多 4 个人开麦）都会写一句并朗读。

声音是浏览器自带的 WebRTC **点对点**传的（Opus，开着回声消除、降噪、自动增益），端到端加密，不经过中继服务；开了麦的人向房间里每个人各发一路（最多 6 路，开了麦的优先），中继服务只帮双方交换连接信息，不存、不记。默认只用公共 STUN，同一 WiFi、普通家用宽带都能直连；手机流量对手机流量这类运营商 NAT 要 TURN 中继，托管方给服务配了 TURN 密钥才有（见「部署」），没配就只有 STUN。

🎤 上的小点是连接状态（绿连上、红连不上、灰闪连接中），下面会写「语音连接中…」「语音连不上对方」或「人太多了，这台设备听不到语音」（每个开了麦的人最多连 6 个人）；麦克风被系统收回（切到后台、来电、别的应用占用）会自动关掉并提示，再点一下重新打开；别人说话时题目朗读会压低一点。

### 游戏画面

每答对一题：队区闪一下队色、飘一个「+1」、比分弹一下、队名下的 8 颗进度点亮一颗，游戏画面同时发生一次看得见的变化；连对 2 题起有 🔥 ×n，「叮」的音高越来越高；连对 3 / 5 题弹「连对 n 题！」、从落后变领先弹「反超啦！」、到 4 分「到一半啦！」、到 7 分「还差一分！」（都朗读）；7 : 7 弹「决胜题！」+ 心跳声，竞技场四周红蓝呼吸光；到 8 分先定格半秒，再把游戏画面放大两倍、镜头跟着赢的那个角色播完到站 / 冲线 / 开花的动画（终局特写），同时全屏撒队色彩纸、播报队名再接一句游戏话（「火箭飞到星星啦！」），3 秒后出结果页。本设备第一次进某个游戏先讲一句规则（「对战开始啦！答对一题，火箭就升高一段，看谁先飞到星星，谁就赢了哦！」，同一个游戏一天内不重复，再来一局也不讲），说完再倒数。

**一题里的角色表演**：角色不只在得分时动，一题从头到尾都在演。等答题时一直在呼吸、重心晃，隔两三秒做一个这个角色的小动作（张望、挠头、伸懒腰、蹦两下、挥手……），等了 4 秒还没按，头顶冒一个「…」的想的泡泡（只是「在想呢」，不计时、不催）；一按数字键头顶亮一个灯泡，身子前倾蓄力，每按一下压一下（赛车踩一脚油门冒口烟、火车「嚓」地喷一口蒸汽、热气球烧嘴喷一下火……）；答对先蓄力压扁、跳起来、落地、举手欢呼，笑眯眯地迸一圈亮片（连对 3 / 5 题翻个跟头）；答错一愣、瞪眼冒汗、摇摇头、甩一甩，1 秒多就重新站好——是「哎呀」不是罚，不后退、不丢分（赛车熄火冒口黑烟、火箭火苗一哑、游泳呛一口水、爬梯子手一滑又抓住、挖宝的镐碰到石头弹回来……）。开了「减少动画」时不跳不晃，只留举手、表情和头顶的小图标。

游戏按章节排定：一个年级的知识点按目录顺序轮流用这几种游戏（上册排完下册接着轮，换年级从头排起），换章节就换游戏；「⚙️ 配置」里可以换一种或「🎲 随机」，只算这一次，下次又回到章节的游戏。手机横屏的矮横条 / 窄竖条自动切成紧凑版，只留角色与轨道。游戏只看比分、不认识题目，和页面严格隔离（见「架构」的不变量）。

**表情与点游戏**：竞技场顶栏每队一排 4 个表情键 🔥 加油 / 😆 哈哈 / 😱 哇 / 😎 厉害（两人一台两排都有，打机器人 / 多设备只有自己那排，只观战的设备在时钟旁有一排），点了从自己这边飞向对方那边、一声「啵嘤」，🔥 还会读一声「加油！」；机器人会回应（收到表情回一个，反超 😎、被反超 😱，赢了 😎、输了给你 🔥）；多设备房间里表情经服务器转给房间里所有人，家长在主持设备上就能给孩子加油。游戏画面也能点：点一下那一队的角色它会有反应（火车鸣笛喷汽、乌龟 / 兔子跳一下、火箭喷一口火、企鹅拍翅膀……每种游戏各不一样），点按处一圈涟漪、小声放这种游戏的得分音，不计分；角色还会在点按处冒一个对话框说一句自己的台词（25 个角色各 3 句，都是催你答题的，比如乌龟「我爬得慢，你答得快我就追上啦！」、火车司机「快答题，火车要开到车站啦！」），带拼音并自动朗读，每个角色的声音快慢高低不一样（乌龟慢而低、兔子快而高）。

**本章战绩**：同一个知识点连着「再来一局」，结果页记「本章战绩：小兔 2 : 1 小猫」，先赢两局的名字旁出 🏆，换知识点或离开清零、不存本地。

**我的小动物**：每一方一只小动物（🐻 小熊、🐷 小猪、🐼 熊猫、🐵 小猴、🐰 小兔、🐱 小猫）：不选就随机、两边不一样，想固定就在「⚙️ 配置」里选（两人一台左右各选各的，「🎲 随机」回到随机）；名字旁、结果页都带它，赛车 / 开火车的司机、热气球的乘客换成它；多设备时随进房发给服务器，别人也看得到。

**机器人**：快慢默认「跟着你」——按你最近几题的平均用时定它的用时（略慢一点），你落后 3 分它再慢一截、领先 3 分它快一截，正确率也跟着你的（略低），每局都能打到六七分才见分晓；它还记得你上次在这一章的节奏（每打完一局机器人都记下这一局的逐题用时与对错，只记最近一次、只在本机），下一局从第一题起就按那个节奏来，答几题后再改跟这一局的；「⚙️ 配置」里仍可选固定的慢 / 中 / 快。它还会说话：自己反超「我领先啦！」、被反超「哎呀，被追上了」、你还差一分「别急别急」、输了「你太厉害了，再来一局吧」、赢了「这次我赢啦，再来一局？」，它那一行冒气泡（带拼音）同时朗读，声音调高一点像机器人；正在读题、读提示的时候它不出声（开局也不说话，免得压在第一题的读题上）。

**背景音乐**：比赛中放这个游戏自己的一首小曲子（振荡器与噪声现场合成，没有音频文件）：21 首各有各的调、速度、拍子和音色——赛跑是木鱼「嘚嘚」的蹦跳小曲，赛车是八分音符推进的小摇滚，火车是摇摆的「哐当哐当」，火箭和点亮星星是钟琴，热气球是飘着的华尔兹，钓鱼是慢悠悠的湖边小调，拆城堡是中世纪风……每首 8 小节一轮（十几到二十几秒），有旋律、低音、铺底和弦和鼓点，旋律的强拍都落在和弦音上；到 6 分冲刺时加快、鼓点加密，朗读和语音说话时压低，结果页停；各首按量出的响度拉平，听着差不多响。「⚙️ 配置」里可以关，🔇 静音时也不放。

**声音**：答对「叮」（连对时越来越高）+ 按游戏一声（赛车轰一下、火箭点火、砖落地咚、融冰咔嚓 + 水滴……）、连对再加一串亮晶晶的上行（赛车是氮气、火车是汽笛）、答错是这个游戏自己轻轻的「哎呀」（赛车熄火噗噗、火车漏气嘶、游泳呛水咕嘟、爬梯子往下一溜、挖宝的镐碰到石头叮、孵蛋咯咯哒、拼图「嗯？」……没有低沉的「咚」）、倒数「嘀嘀嘀」后「开始」是这个游戏的一声（发令枪、汽笛、点火、甩竿、小号、号角……）、自己每按一下数字键很轻的一声（赛车踩油门、火车喷蒸汽、火箭火苗、热气球烧嘴……机器人按键不出声）、弹出提示「啵」、胜利小号声加欢呼，都是 WebAudio 振荡器和噪声现场合成的，没有音频文件；得分音红队偏左、蓝队偏右（立体声），安卓上答对短震一下、答错震三下；每到一半（4 分）那一队的角色做一下「点一下」的小动作；规则句、弹出提示、播报用的是预合成的朗读片段。**屏幕上的提示语也会读**：「练习」页打开读「怎么练？」和当前那张卡的说明、换卡读那张卡的，问名字读「你叫什么？」，点 ✕ 读「要退出比赛吗？」；房间里二维码页读扫码说明、有人进来读「红队已进入…」、连接状态窗口读「等大家进来… 红蓝两队都进来就自动开始」，输口令面板、连不上、房间关了这些提示出现就读——还不太会认字的孩子靠听就知道下一步做什么（同一画面不重复读，🔇 时不读）。

**结果页**：上面一张战报卡，左边 🏆 谁赢、比分、用时、每人「答 n · 对 m」（输的一方写「差一点点！」）、本章战绩，右边「下一章 / 再来一局 / 不玩了」和「分享战绩」——手机横屏上整张卡在第一屏，不用往下滚找按钮；卡片下面是一条红蓝赛跑的比分走势（反超的地方打点），再下面列出这台设备答错的题（题干带拼音、正确答案，点了朗读；多设备只列自己的），最后一个「再练一遍」进这个知识点的练习页——题目流是确定性的，只记种子和题号就能重现，不存本地；三种模式都是「下一章」（最大，接着打本册下一个知识点、游戏换成那一章的，最后一个知识点写「这一册都打完啦！」）、「再来一局」（同样的人和游戏，换一组题）、「不玩了」（回地图）。

### 🥊 打怪兽：限时 Boss 战

另一种玩法，孩子之间不再互相比：在「练习」页顶上切到「🥊 打怪兽」页签，一起（或各自）打一只充气不倒翁恐龙「捣蛋龙」——它把大家的星星抢走了。

- **限时**：默认 90 秒（「⚙️ 配置」里可选 60 / 120 秒），题目不限量；最后 10 秒计时器变红、音乐加快、四周暖红的呼吸光，每拳多 1 分；时间到哨声一响就结束。顶栏的 ⏸ 可以暂停（题目盖住、计时和音乐都停，「继续打」先 3-2-1），切到后台也会自动暂停。
- **得分**：答对一题打一拳得 1 分；同一个人连着答对，第 3 题起每拳多 1 分；答错不扣分，这一拳打空、连击断掉（答错要等 1 秒多，蒙比想慢）。分数就是打在捣蛋龙身上的伤害，结果页同时写答对几题、最高连击。
- **Boss 链**：一只打倒（血量 5 / 10 / 15，之后每只 20；两个人翻倍、按时长缩放，打倒那一拳多出来的伤害算到下一只身上），下一只更大的马上登场——第二只戴泡沫头盔、第三只戴纸王冠、再往后是金色的；打倒几只就是几颗星（最多三颗）。
- **谁来玩**：一个人打（手机竖着拿也行）、和机器人（「一起打」时机器人当队友、跟着你的节奏再慢一点，「各打各的」时按配置里的快慢比得分）、两人一台（一左一右）；两个人可以选「一起打」（打同一只，1.5 秒内先后打中是合力拳，最后看谁得分最高、戴 👑）或「各打各的」（各打一条 Boss 链，比得分）；也可以各用各的设备：和对战一样建房间、扫二维码或输口令进来，「一起打」两个人到了就自动开始（最多 12 人），「各打各的」红蓝两队都有人就开始（每队最多 6 人）。计时以服务器为准，每台设备只放自己那一栏作答区，其他人缩成舞台下面的一排头像条（得分、正在按、连击、🎤）；台上每队最多两个人（最近打中的轮换上台），其他人坐在观众席举着自己小动物的牌子，答对了从观众席飞出一个发光的能量拳；表情、语音和对战一样能用。
- **竞技场**：舞台是主角——iPad / 电脑上舞台全宽、约 300 像素高，下面是作答区；手机横屏一个人时左舞台右作答、两个人时舞台在中间；顶栏是大号计时器（一圈进度）和打倒了几只。作答区和对战的一样（题干带拼音、数字键盘 / 选项卡），头部写得分（加分时飘一个 +n）和连击 🔥。
- **画面**：拳台、聚光灯、摇荧光棒的观众、角落一面锣；拳手就是自己的小动物（和机器人一起打时旁边是个小机器人），戴队色护头和拳套，动作是用「骨骼姿势片段」写的（弹跳晃拳、擦鼻子、蓄力、出拳、庆祝之间交叉淡入）。每按一个数字拳套亮一格（蓄力），答对立刻出拳，连击越高招式越大：直拳前冲一步；勾拳扭身抡一道弧，把捣蛋龙打得往侧后方歪；上勾拳先蹲再往上窜，把它打得离地弹起；第 5 题起是旋风拳，先转一圈再冲出去，拳套变超大，捣蛋龙转半圈、镜头往前推。两个人 1.5 秒内先后打中是合力拳：两只拳套一起打到、冒一圈金光，再朝对方举拳碰一下。捣蛋龙像不倒翁一样被打歪再弹回来、从布袋里迸出星星；第三只（戴纸王冠）会吹泡泡挡在肚子前，拳头先把泡泡打破再打中；血少了冒汗、蚊香眼；打倒时停一下再慢动作翻飞、泄气乱飞、缩小挥手蹦走，下一只从天而降；答错是挥空转一圈；没人打中它就轮流表演——跳挑衅舞、张大嘴吼（拳手被吹得往后仰、耳朵和护头带子飘起来）、从布袋里掏出果冻球扔过来（拳手一低头躲开）；时间到它一屁股坐下喘气、挥手跑掉。打不坏、不流血。
- **结果页**：一起打是「一起把捣蛋龙打倒了 n 次！」+ 星星，各打各的是比分 + 胜方；每人一行得分、答对几题、最高连击、合力拳，得分最高的 👑；一个人打会记下这台设备上每个知识点、每种时长的最好成绩，打破了写「🏅 新纪录！」（设置页「一个人打」那张卡上也写着最好成绩）；下面是每人一条的得分走势和我答错的题；同样是「下一章 / 再来一局 / 不玩了」。
- **声音**：一首自己的 Boss 战曲（小调、130 拍，最后 10 秒加快到 160）；开打是一声锣，出拳「嘭」（勾拳带风声、上勾拳往上一挑、旋风拳先蓄力再大轰）、打在充气恐龙身上「boing」（分越多音越高）、挥空「呼」、打倒时「噗——」泄气再接一小段胜利短句、时间到裁判哨；「打倒啦！」「第二只来啦，它戴着头盔！」「最后十秒，冲呀！」「时间到！」都朗读；6 秒没人打中，捣蛋龙轮流跳挑衅舞「来打我呀！」、吼一嗓子「嗷呜——我可厉害啦！」、扔果冻球「请你吃果冻！」；点一下捣蛋龙它咯咯笑「哈哈，好痒！」，点拳手、观众、锣也各有声音。

## 拼音与朗读

- **拼音**：中文模式下练习页的所有汉字（题干、选项、页头、答错讲解、结算）都逐字注音（语文考认字的字除外：田字格里的大字、听音 / 看拼音 / 看图选字的楷体选项都是不带拼音的纯文字），字体用为初学者设计的 [Andika](https://software.sil.org/andika/)（单层 a / g，OFL，自托管）。每条中文词条配一条与汉字逐字对齐的拼音（各内容包的 `pinyin.ts`、`src/locales/shell.ts`），一 / 不按实际读音标变调，有测试保证音节数与汉字数相等。
- **朗读**：不用浏览器 TTS 读汉字。题目文字按「数字 / 汉字短语 / emoji 的名字 / 运算符与括号的读法」切成片段（`src/engine/speech.ts`），连续的短语、运算符和一个「槽」（一个数或一个 emoji 的名字）并成一条自然的话（「小猪 · 有14个 · 苹果，小狗 · 比小猪 · 少8个」「9 · 加5等于几」；一条最多一个槽，量词留在数字后面、动词 / 介词 / 连词贴向后面），逗号 / 句号变成停顿；每个片段是一条预先合成好的 mp3（`public/audio/`，Microsoft Edge 神经语音，来源见 `public/audio/CREDITS.md`），播放时整句按 AudioContext 的时钟一次排到时间轴上（片段之间 30 ms、停顿 280 ms），不是一条播完再起下一条：「9 + 5 = ?」读作「九 · 加 · 五 · 等于几」，「🐷 有 14 个 🍎，🐶 比 🐷 少 8 个」读作「小猪 · 有十四个 · 苹果 ，小狗比小猪 · 少八个」，「(3 + 4) × 5 = ?」读作「括号 · 三 · 加 · 四 · 括号 · 乘 · 五 · 等于几」，「🐰 从左数排第几个？」读作「小兔子 · 从左数排第几个」。100 以上的数按课本读法拆成几段（3005 → 三千 · 零 · 五），所以万以内的数不用每个都录一条。缺片段（比如刚加了新题型还没重跑脚本）才退回浏览器 TTS。
- **数的读法**：分数「3/8」画成上下两层、读「八分之三」（英文 three eighths）；100 以内的一两位小数、分数和前后的字并成一句读；年份按位读（2024 年 → 二零二四年），日期「3 月 5 日」读成「3月 · 5日」（「2 月」读「二月」，「2 小时」读「两小时」），中文里的时刻 14:30 读「十四点三十」；比大小的「○」读「和」。万以上的数按级读（21893095 → 二千一百八十九万三千零九十五），屏幕上照课本连写；四年级的记号读成字：60° 读「60度」、∠1 读「角1」、a // b 读「a 平行于 b」、a ⊥ b 读「a 垂直于 b」、≈ 读「约等于」、80米/分 读「80米每分」。英文界面的长度、质量单位写符号（mm、kg），合成时读成单词（millimeters、kilograms）。
- **提示语**：让孩子照着做的提示（知识点「练习」页的「怎么练？」与四张卡的说明、问名字、退出确认、房间页的扫码说明 / 连接状态 / 输口令 / 错误提示）在页面打开或切到那个功能时自动读一遍（`engine/voice.ts` 的 `sayKeys`），与读题共用一个独占通道，新的打断旧的；只有对战里点 🔊 读题例外——那句必须读完，期间另一方点的、自动读的新题、要读的提示都排在后面（连对 / 反超这类弹出提示则跳过）。写这类文案时注意「」括号会把句子切成几段，每段要是自然的短语，别用圆括号（会读出「括号」）。
- **音频包**：`npm run audio` = `scripts/collect-speech.mjs`（跑遍所有生成器与外壳固定句收集片段 → `src/audio/corpus.json`）+ `scripts/build-audio.py`（edge-tts 合成、裁静音、响度归一、转 24 kHz 48 kbps mp3 → `public/audio/` 与 `src/audio/manifest.json`），现在中文 39383 条、英文 22904 条，共约 625 MB（语文每个题目条目逐条收一遍，一到三年级的课文句子多；三、四年级数学的文字题、大数、小数与算式最多；短语里的数与 emoji 名字并进短语后片段是原来的 5–6 倍；嫌音频包大可以把 `src/engine/speech.ts` 的 `MERGE_MAX` 调小，或把音频脚本的码率从 48k 降到 32k）。有测试保证语料与代码一致、每个片段都有文件。多音字在个别上下文里被合成读错的（比如「从前数第几个」的「数」读成 shù；序数「第一声」「第一笔」「第一个」的「一」要读 yī，不能跟着「叫了一声」读成 yì；题目里的第几个、第几声也都用汉字写，阿拉伯数字夹在中文句子里合成出来是读数字的调子），合成脚本里有一张读法表，把送去合成的文字换成读音唯一的同音字，屏幕上的字不变；这些片段的文件名跟着换过的文字走，页面按一张小别名表找到它们，已经缓存过旧音频的设备也会重新下载。
- **语文的拼音与朗读**：课文、词语、问答的拼音不在词条里配，而是每个年级一张按上下文注好的拼音表（`content/chinese/grade<n>/py.ts`：键是句子或词语，值与汉字逐个对齐；轻声、一 / 不变调、多音字按课文里的读法——种田 zhòng、长出 zhǎng、盛满 chéng、雨点儿 yǔ diǎn r；单独一个生字按它在识字表里的读音，比如二年级《寒号鸟》的「重」读 chóng），测试查每课要用的都在表里、没有多余的。课文句子、听音的字词、图名、答案这些**中文内容在英文界面也用中文的声音读**（朗读片段带一个「用中文读」的标记）；拼音不让语音合成念字母——一个音节读一个读音唯一的同音字（bā 读「八」），声母韵母读课本的呼读音（b 玻、p 坡、m 摸）；听音题和答案里的多音字按这个字在本课的读音给个词读（「长短的长」「长大的长」「重复的重」）——「X 的 X」末尾单独那个字合成时也常读成最常见的音（高兴的兴读成 xīng），合成脚本把这些词的末尾换成读音唯一的同音字再合成。
- iOS / Safari 要在用户手势里解锁音频：任何一次触摸都会顺手解锁，之后自动读题不再受限；直接用地址打开练习页时第一题会等到第一次触摸才有声音。

## 部署

纯静态站：`npm run build` 后把 `dist/` 整个放到任何支持 HTTPS 的静态托管（nginx、对象存储、Pages 服务都行），不需要服务端；`base: './'`，放在子目录也能跑。

- **缓存与更新**：已注册 Service Worker（vite-plugin-pwa，`registerType: 'autoUpdate'`），预缓存只有页面外壳（代码、字体、图标，约 2.6 MB，几秒装好）；朗读片段不预先下载——练习页进来时只取这一轮要读的，读到哪条取哪条，取过的存进另一个缓存、再读就不用联网（文件名是内容哈希，页面打开后会把缓存里已经不用的旧片段清掉）。**不保证离线使用**：用过的内容断网时多半还能读，没用过的片段断网时退回浏览器 TTS。首页页脚最上面的版本卡片显示当前版本（构建时刻），点「检查更新」会和服务器上的 `version.json`（构建时一起生成）比对，有新版本就下载并自动刷新，没更新成功还能「重新安装」（清掉缓存重新下载，学习记录不丢）；重新部署后开着的页面回到前台会自己换新版本（在对战里就等退出竞技场再换）。自己部署时**必须是 HTTPS**（局域网 http 地址不行，Service Worker 不会注册）。
- **安装提示**：没从主屏幕打开时，首页顶上有一条「安装 同步练-对战版」提示（给家长看的，不出声、不遮按钮）：Android / 电脑 Chrome、Edge 点「安装」直接弹系统安装框；iPhone / iPad 点「怎么做」看步骤（Safari 分享 → 添加到主屏幕）；微信 / QQ 里教先在浏览器打开。关掉 3 天后再提示，装好了不再出现；电脑上只在能一键安装时提示。逻辑在 `src/engine/install.ts`（可单测）+ `src/stores/install.ts`，画在 `components/ui/InstallBar.vue`。
- **搜索引擎**：应用是 hash 路由，搜索引擎只看得到根地址，所以构建前 `scripts/seo.mjs`（`prebuild` / `predev` 自动跑）按目录生成一套不用 JS 的静态页放进 `public/`：每个上线课程一张目录页（`math/g1/`）、每个知识点一张（`math/g1/s1-05-carry-add.html`：介绍、固定种子生成的示例题含选项与答案、同单元其它知识点、「⚔️ 打一局」深链到对战设置页、「安静地练」深链到练习页）、帮助页一张（`help/`，常见问题带 FAQPage 结构化数据），都带标题 / 描述 / canonical / Open Graph / 面包屑 JSON-LD，每个知识点页还有三段专属正文「怎么学 / 常见错误 / 家长怎么陪」与搜索词（`src/content/math/<年级>/seo.ts`）、上一个 / 下一个链接，页脚互相链接；另生成一张 `404.html`（不索引，服务器 `error_page 404 /404.html`）。入口页 `index.html` 的标题、描述、JSON-LD 与应用挂载前的静态简介也由同一份目录生成（写在 `<!-- seo:head -->` / `<!-- seo:body -->` 两段标记之间，别手改，有测试保证与目录一致）。页面文案在 `src/seo/site.ts`。
- 构建时若本机 `.env` 里有 `SITE_URL=https://你的域名`，页面会带上 canonical / Open Graph 的绝对地址，并生成 `robots.txt` 与列出全部静态页的 `sitemap.xml`；没有就不带（页面照常可用）。分享图 `public/og.png`（1200×630）由 `npm run og` 渲染。静态页与分享图不进预缓存；托管时最好让未命中的地址直接 404（不要回退到 `index.html`，会被搜索引擎当成软 404）。
- **对战中继服务**（只有「各用各的」需要）：`npm run build:server` 打成单文件 `dist-server/battle.mjs`，用 Node 跑（`PORT` / `HOST` 环境变量，默认 127.0.0.1:8787；`ALLOWED_ORIGINS=https://你的域名` 只接受本站页面的连接，逗号分隔可以多个），托管方把同源的 `/ws` 反向代理到它（要放行 WebSocket 升级，并传 `X-Real-IP` 或 `X-Forwarded-For`——按 IP 限制连接数与猜口令用）。网站与服务要用同一次构建：连接时核对出题相关源码的哈希，旧页面遇到新服务会自动更新重载。没有它网站照常可用，只是那张卡置灰。
- **语音通话的穿透**（可选）：语音是点对点的，服务默认只发一份公共 STUN 清单；要让手机流量对手机流量也能连上，给服务再配 `TURN_KEY_ID` / `TURN_KEY_TOKEN`（[Cloudflare Realtime TURN](https://developers.cloudflare.com/realtime/turn/) 的密钥，按流量计费、有免费额度），服务会向 Cloudflare 换 2 小时有效的临时凭据发给房间里的人，密钥本身不出服务器。托管方的响应头要放行本站的麦克风：`Permissions-Policy: microphone=(self)`（写成 `microphone=()` 就开不了麦）。
- **访问统计**（可选）：本机 `.env` 里同时写 `VITE_UMAMI_SCRIPT=https://你的统计站/script.js` 与 `VITE_UMAMI_WEBSITE_ID=<站点 id>`，正式构建会往 `index.html` 与每张静态页的 `<head>` 里加一行 [Umami](https://umami.is)（开源、无 cookie）的上报脚本；`data-domains` 取 `SITE_URL` 的主机名，本机预览不上报。两项都不配就什么都不加。逻辑在 `src/engine/analytics.ts`（可单测）：入口页关掉 tracker 的自动记录，翻页由路由上报，上报前去掉查询串、把多设备房间的房间号换成 `room`（房间号是进房的钥匙，不进统计库）；静态页由 tracker 自己记。用了 Content-Security-Policy 的话 `script-src` 与 `connect-src` 要放行统计站的域名。
- **安全**：纯静态、无账号、无 cookie，不存别人的数据。别人发来的文字（昵称、正在输入的内容）一律当纯文本渲染；设备身份只在连接时发给服务器，服务器给别人看的是它的哈希（拿不到别人的身份就冒充不了）；服务有消息大小 / 频率 / 连接数 / 猜口令次数的限制；建议托管时加一条 Content-Security-Policy（脚本、样式、字体、音频、图片只从本站取，图片另加 `data:` 给二维码，`connect-src` 加本站的 `wss://`，`frame-ancestors 'none'`），本项目线上就是这样配的；语音走 WebRTC 不受 `connect-src` 管，`Permissions-Policy` 只放行本站的 `microphone=(self)`。语音信令只转给同房间在线的人（offer 只转发开着麦的人发的），形状不对的丢掉。服务里的房间号 / 口令 / 题目种子都是加密随机数，建房按 IP 限量，猜房间号与猜口令一样计次，发送前看写缓冲、每条消息都兜住异常（一条坏消息不会让所有房间清空），TURN 临时凭据只给不止一个人在线的房间。客户端判分、服务器不复算（家庭游戏不防作弊）。

## 技术栈

Vite + Vue 3（Composition API）+ TypeScript + Pinia + Vue Router（hash 路由，`base: './'`），原生 CSS + design tokens，不用 UI 框架；vite-plugin-pwa 做页面外壳预缓存与朗读片段的按需缓存；对战游戏是自研的 Canvas 2D 小引擎；中继服务是 TypeScript + `ws`；测试用 Vitest（生成器与状态机跑在 node，组件测试用 happy-dom，中继服务真起在随机端口测）。音频包由 Python 脚本生成（edge-tts + numpy + ffmpeg），运行时不需要。

### 几条不变量

- **作答只落到 numpad / choice**：题干可以用任意 `StemPart` 可视化，答案必须是数值或选项 id，这样每个生成器都能单测（多种子跑结构自洽、答案正确、干扰项合法、签名去重）。
- **生成器产出 `LStr`**（字面量或 `{ k, p }` 词条键），渲染期按当前语言 `translate`，切语言即时重排；界面文案走 `ui(key)`。孩子会看到的中文词条都要在 `pinyin.ts` 配拼音（测试会查），朗读片段从渲染后的文字里切出来，改了文案要重跑 `npm run audio`（测试会查语料是否过期）。
- **知识点 id 全局唯一**（生成器注册表是全局 Map），新年级用不同前缀。
- **引擎不认识内容**：`@/engine` 不导出 catalog，目录相关从 `@/engine/catalog` 导入；内容包只依赖 `@/engine` 与 `@/types`。
- **内容包可以按需加载**：目录（单元 / 知识点树、知识点名）随首页加载，生成器与题目文案可以等进这门课的页面之前再加载（现在语文和三、四年级数学是这样，一、二年级数学静态导入）。视图里照旧同步出题，前提是路由守卫已经按地址里的学科年级或知识点把包加载好；地址里看不出课程的多设备房间页，收到快照时自己先加载再交给比赛。
- **皮肤靠 `<html data-theme>`**：`App.vue` 按当前学科切换，颜色全走 CSS 变量。
- **对战与内容解耦**：游戏只吃 `{ red, blue, target, phase, winner, lastPoint }` 和瞬时事件，不认识题目；题目流由 `(kpId, seed, 序号)` 确定，所以对手 / 观战 / 重连都能复现同一道题，中继服务不用传题；比赛状态机是纯函数，单设备在页面里跑，多设备时同一份跑在中继服务上（服务器只管房间、座位、谁答到第几题、比分与胜负，客户端判分后报结果；服务器发整份房间快照，每房间每秒最多 10 次，瞬时事件单独发；快照里的身份都是设备 id 的哈希）。页面收到不认识的知识点当「没有这个房间」、不认识的皮肤退到这一章排到的游戏，不会因为建房者乱填而整页出错。
- **游戏与页面隔离**：canvas 游戏实现 `battle/game/contract.ts` 的 `GameModule`，由 `GameHost` 装进竞技场的固定盒子里；游戏没有 CSS、不接触摸（`pointer-events: none`）、不出声、拿不到 store / 路由 / DOM，按需加载，加载失败或抛错自动换保底画面（两条队色进度条）。`arena-isolation.test.ts` 用每种游戏挂载竞技场，断言盒子之外的 DOM 完全一致。新游戏 = `battle/games/<id>/` 一个目录（model / render / index）+ 注册表一行 + 词条。

### 加一个年级（例：五年级数学）

1. 按当年人民教育出版社的电子教材目录（不是旧版）新建 `src/content/math/grade5/`，照 `grade3` / `grade4` 的结构：`curriculum.ts`（单元与知识点，知识点 id 用新前缀 `m5s<册>-<目录位置两位>-<语义名>`，☆ 综合与实践置 `numbered: false`；新版课本只出了一册就只写那一册的单元，选年级页另一册自动画「敬请期待」占位卡）、`titles.ts`（知识点英文名与标题拼音）、`course.ts`（目录，随首页加载）、每个单元一组 `generators/<单元>.ts` / `lang/<单元>.ts`（词条键都以 `m5.` 开头，别与已有内容包重名；`shape.*` / `sym.*` / `emoji.*` 从 `content/math/shared/` 取）/ `seo/<单元>.ts`，外加三个汇总的 `generators/index.ts`、`lang/index.ts`、`seo.ts` 与包入口 `index.ts`。
2. `src/engine/catalog.ts`：`registerCourse(mathGrade5, () => import('@/content/math/grade5'))`（目录从 `course.ts` 导入，整个包按需加载），并把 math 学科里 `grade('g5')` 改成 `grade('g5', 'math-g5')`；`public/covers/` 放有的那几册封面；`audio/corpus.ts`、`seo/site.ts` 各加一行直接导入整包（它们要跑遍所有知识点），`seo/site.ts` 的 `KP_SEO` 合并新包的 `seo.ts`。
3. 照 `grade4` 建测试：`generators/__tests__/generators.test.ts`（全部知识点的结构、答案自洽、第 1 档题量）、`__tests__/pinyin.test.ts`（词条拼音对齐），每个单元一份从题目反推答案的专项测试；渲染冒烟测试单独一个文件（照 `render-math4.test.ts`），`speech.test.ts` 的知识点列表加上新包。
4. `npm run audio` 生成新增片段的音频（先 `node scripts/collect-speech.mjs` 看一眼新片段里有没有单独成片段的多音字）；`npm run seo` 更新 `index.html` 的简介（测试会查）、`npm run og` 重画分享图；`scripts/videos.mjs` 的 `BOOKS` 补上同步课教材 id（有几册补几册；语文另在 `OLD_BOOKS` 补旧版教材两册，找替代视频用）、`MATH` 表补上新知识点对应的章节名（新教材这一节还没有同步课的，数学在 `OLD_MATH` 手写旧教材里讲同一件事的那一节），再 `npm run videos`（测试会查每个知识点都有视频链接）。
5. 完。选择页、地图、练习、主题、拼音、朗读、对战、帮助页、静态页与 sitemap 自动生效。

### 加语文的一个年级（例：三年级语文）

1. 新建 `src/content/chinese/grade3/`，照 `grade2`：`course.ts` + `titles.ts`（随首页加载的目录、知识点英文名与标题拼音）、`curriculum.ts`（每课一个知识点，id 前缀换成 `c3s…`）、`lessons-*.ts`（每课一份材料，格式见 `content/chinese/shared/spec.ts`：生字、写字、词语表、课文句子里挖空、问答、多音字、近义词、部首查字法……，`mix` 定三档出哪些模板）、`generators.ts`（`definePack` 一行）、`py.ts`（材料里要注音的中文 → 拼音，按课文上下文注）、`seo.ts`、`index.ts`。新的题目模板加在 `shared/makers.ts`，新的题目要求加在 `shared/prompts.ts`；材料里出现了新字要重新生成 `shared/readings.ts`（测试会查缺的字）。
2. `catalog.ts` 里 `registerCourse(chineseGrade3, () => import('@/content/chinese/grade3'))`（目录从 `course.ts` 导入，整个包按需加载）并挂 courseId；照 `grade2/__tests__/` 建测试（材料能出题、答案对得上、考认字的字不泄露、每课第 1 档题量、拼音表查全 / 对齐 / 没有多余），`shared/__tests__/distractors.test.ts`、`poly-say.test.ts` 加上新包，照 `render-chinese2.test.ts` 建一份渲染测试。生字里的多音字单读合成出来可能是别的音：在 `makers.ts` 的 `POLY_SAY` 按本课读音给个词，末尾读错的再登记到合成脚本的 `POLY_TAIL`。
3. `npm run audio`、`npm run seo`、`npm run og`。

### 加一个学科（例：英语一年级）

1. 新建 `src/content/english/grade1/`（同上五件套）。有新题型就在 `types/models.ts` 扩 `QuestionType` / `StemPart`，在 `components/<学科>/` 加教具，在 `QuestionRenderer` 加一个分支；作答仍收敛到 numpad / choice。
2. `catalog.ts` 里 `registerCourse`，把该学科 `status: 'soon'` 改 `'live'`、对应年级挂 courseId；`seo/site.ts` 的 `SUBJECT_COPY` 加一条这门学科怎么出题、答错怎么办。
3. `styles/themes.css` 已给 `[data-theme="english"]` 一套配色，按需微调。
4. `npm run audio` 生成新增片段的音频；`npm run seo`、`npm run og` 同上。
